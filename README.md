# 📊 NovaMart Sales & Business Analysis – Power BI

## 📌 Project Overview

This project presents an interactive **Power BI dashboard for NovaMart**, created to analyze business performance and generate meaningful insights from sales and customer data.

The project focuses on transforming raw business data into an interactive dashboard that helps users understand **sales performance, customer behavior, product performance, and key business metrics**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall business and sales performance
- Identify important trends and patterns
- Compare performance across different categories and segments
- Analyze customer and product performance
- Track important business KPIs
- Create an interactive and user-friendly Power BI dashboard
- Support data-driven business decision-making

## 📂 Dataset

The project uses the **NovaMart dataset** provided in Excel format.

The dataset was analyzed and transformed before creating the Power BI dashboard.

### Data Preparation

The following data preparation activities were performed:

- Checked the dataset for missing values
- Identified and handled null/blank values
- Checked for data inconsistencies
- Validated column data types
- Cleaned and transformed the data using Power Query
- Prepared the data for analysis and visualization

## 🔍 Analysis Performed

### 1. Sales Analysis

Analyzed sales performance across different categories, segments, and other relevant dimensions to identify high- and low-performing areas.

### 2. Product Analysis

Examined product-level performance to identify products contributing significantly to overall business performance.

### 3. Customer Analysis

Analyzed customer-related metrics to understand customer contribution and purchasing patterns.

### 4. Category & Segment Analysis

Compared different categories and customer segments to understand which areas generate better business results.

### 5. Time-Based Analysis

Analyzed business performance across different time periods to identify trends and changes in performance.
